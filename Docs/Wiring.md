# Wiring

> This file has all wiring you need to make this project

## Note - ⚠️Previous design has MCU and Sensors so it needed wiring but this improved design has 
1. Mist Maker - Powered by 24v DC charger
2. LED Strip - Powered by USB charger
3. Exhaust Fan - Powered by its own AC plug 

That's why there's no neeed to a wiring diagram, everything is powered from a singple extension board with AC and USB socket/port.
