# Wind Tunnel

## Overview
 
A DIY wind tunnel to test test model rockets parts like fins and nose cone. This project is part of my Silicon Labs eco-system. Just like my previous Fume absorber project, this project is also to help me achieve my final goal of building a TVC based model rocket. This wind tunnel will help me to test aerodynamic of parts like fins, nose cone etc.
